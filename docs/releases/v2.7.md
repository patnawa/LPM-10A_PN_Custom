# TX PN 2.7 — FLASH reliability, length safeguards and battery startup

Unofficial firmware for the **LPM-10A TX tester only**. On 2026-09-19 the owner
reported "Test pass on new firmware tx rx" for TX PN 2.7 and RX PN 1.2.
The release binary is unchanged from the tested candidate. This is a general
functional pass on their units, not certification of every condition or revision.

## Changes from PN 2.6

- FLASH negotiation retries back off 4 → 8 → 16 seconds; retain the working
  window until session exit. Fixes starvation reproduced with slow link partners.
- Enforce full minimum 1500 ms link hold and 1000 ms PHY-off intervals, including
  jittered or bunched message delivery. Dispatch delays may lengthen intervals.
- Mark partial per-pair length averages with `~` when only 1–3 of 4 runs yield
  a reading. Rerun/check the connection; a full reading is not proof of accuracy.
- Print `OVR` instead of wrapping an unrepresentable display value to a tiny number.
- Ignore queued calibration redraws after leaving the Length screen.
- Initialise the battery debounce counter at startup before tasks use it.

Includes the previous SCAN wrap/resume/timer-path fixes. File size and
bootloader-facing image name are unchanged from PN 2.6.

## Verification and remaining limits

Full TX verifier passed: 61 screen states in each language, 39 SCAN checks,
51 new reliability checks, 65,536 maximum-NVP conversion values and 7,776
calibration/unit boundary vectors. Twelve SDK audit tests and assembler tests pass.

The owner report does not enumerate edge-case, PoE-supply or electrical tests.
Links requiring >16 seconds may still fail; nearby cable pairs remain merged by
the vendor filter; raw PHY status/range validation, other interrupt queue calls,
battery sampling gaps and PoE classification/concurrency remain open. QC and
Speed have UI/code-integrity coverage, not full electrical-protocol emulation.

## TX update and recovery

1. Verify the checksum: `certutil -hashfile LPM-10A-TX_PN2.7.bin SHA256`.
2. Power off, then hold **M + Power** until the update screen appears.
3. Connect USB-C and copy the TX binary to the removable drive. Wait for the
   update; do not unplug during writing.
4. Power-cycle; About should read `Software:PN 2.7`.

If refused, the documented fallback filename is `LPM-10A-TX_V2.0.7_260610.bin`.
Retain PN 2.6 and a matching stock recovery image. The vendor original is not
attached; this report does not prove every rollback scenario. Flash at your own risk.
