# TX PN2.27A — faster carrier switching and Analog alignment

The owner confirmed on 2026-09-22:

> test pass on LPM-10A-TX_PN2.27A-analog-alignment.bin and rx1.24

This release publishes that exact TX image. RX PN1.24 remains the current
receiver firmware; no RX change is required for a receiver already on PN1.24.

- Specialized carrier GPIO updates reduce the enable path from **258 to 17
  instructions** and disable from **284–285 to 42–43 instructions** in actual
  Thumb execution. Other pin fields and the existing OFF levels are preserved.
- Analog modulation is nominally **816.832 Hz**, closer to the RX filter's
  target. The two existing mode buttons read **Digital 454 kHz** and
  **Analog 817 Hz**, with the existing layout.
- Digital coding, the shared timer, carrier duty and drive settings remain
  unchanged. The PN2.26 QC and Length fixes are retained.
- The Analog update adds 64 flash bytes and no persistent RAM. The update
  container remains **401,408 bytes**.

Validation: the complete pre-release TX suite passed **516 tests**. The
paired experiment exercised **60,006 actual-code timer IRQs** and **2,096
modeled RX acquisitions** on RX PN1.24 and PN1.23G. Each candidate passed
17,834 key/navigation interrupt placements, including pause, RIGHT, mode
changes and reentry. Default and historical profiles reproduce their pinned
bytes after promotion. An additional promotion run passed 37 profile/component
checks and 12 publication checks.

Instruction counts and weak-input results are emulator/model measurements.
The device confirmation records the owner's reported test pass with RX PN1.24;
it does not quantify physical gain, range or cable-selection precision. Analog
half-cycles use 606/707 microsecond intervals to achieve the new mean frequency.

**Install `LPM-10A-TX_PN2.27A-analog-alignment.bin` on the TX tester.**
Power off, hold **M + Power** to enter update mode, connect USB-C, and copy the
TX file onto the removable drive. Wait until copying completes, then power
off and on. About should show `Software:PN2.27A`.

If QC requests Init, disconnect every cable and hold Right before reconnecting
the cable. Successful PN2.25/PN2.26 calibration remains usable. For rollback,
install the [PN2.26 TX release](https://github.com/patnawa/LPM-10A_PN_Custom/releases/tag/v2.26)
using the same procedure.
