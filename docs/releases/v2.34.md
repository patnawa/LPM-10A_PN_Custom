# TX PN2.34 — Cable Test requests belong to their screen visit

This prerelease fixes queued Cable Test keys that survived Back. On PN2.33, a delayed OK could reopen the Switch result layout after canceling an RX-unit test; two delayed OKs could run a complete 792-reading Switch test.

**Validation: ARM CPU/GUI emulation and reproducible builds. Physical PN2.34 testing is pending.** The owner will test both units after publication.

Install **`LPM-10A-TX_PN2.34-cable-session.bin`** on the TX tester.

Cable Test requests now carry their visit generation and selected mode. Back, reentry, and mode changes invalidate old requests. Pending Start requests are coalesced, keys during measurement are ignored, and a full GUI queue releases the pending request so the next key can retry. The payload uses the existing inline GUI queue; it does not allocate heap memory.

The existing Switch/RX-unit measurement and classification rules, wire colors, sampling, and thresholds are preserved. Other functions have no intentional changes; current-image regression coverage includes Length, QC, SPEED, and tone. In particular, Switch mode still cannot prove every wiring fault through a switch's transformer/center-tap paths. The stricter check withdrawn in PN2.33 has not been restored without physical port measurements.

The patch adds 772 bytes of code and 16 bytes of session RAM. The image is 405,504 bytes (one 4 KB page larger than PN2.33). Full SDK discovery passes 609 tests with one optional PNG-preview skip. The focused run passes 79 tests, including current-image Length text/progress, QC, SPEED, tone, and immutable build profiles. See the [implementation and validation report](https://github.com/patnawa/LPM-10A_PN_Custom/blob/v2.34/docs/RX-TX-RESILIENT-2026-09-26.md) for the final regression results.

Installation: tester off, hold **M + Power**, connect USB-C, copy the TX file onto the drive, wait for completion, then power off and on. About should show `Software:PN2.34`. If the bootloader requires its stock filename, rename the copy to `LPM-10A-TX_V2.0.7_260610.bin`. If QC asks for Init, disconnect cables and hold Right until it succeeds.

Device check: test a known-good cable in Switch and RX-unit modes; repeat OK rapidly, press Back before a test begins, change modes and reenter, then perform an ordinary Retry. Confirm no canceled test starts or wrong-mode result appears. Check Length, QC, SPEED, FLASH, PoE with suitable equipment, and Digital/Analog tone as usual.

Rollback: install the [owner-tested PN2.33 release](https://github.com/patnawa/LPM-10A_PN_Custom/releases/tag/v2.33). Its bytes and build profile remain unchanged. RX PN1.30 and PN1.31 are compatible with this TX build.
