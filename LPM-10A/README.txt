Model: LPM-10A
Version: V2.0.7
Release Date: 2026-06-10

----------------------------------------

[ VERSION DESCRIPTION ]
- Fixed an issue where measuring speed after measuring length caused an error.
- Fixed an issue where the device would shut down unexpectedly during length measurement.

----------------------------------------

⚠ IMPORTANT NOTES
- ！！This version supports V2.x.x hardware only.
- Do not disconnect USB during update
- Use firmware only for the correct model
- Interrupting upgrade may damage the device

----------------------------------------

[ UPGRADE STEPS ]
1. Turn off the device, press and hold the M button and the power button at the same time, and the device will pop up the firmware update interface. Insert the USB Type-c data cable to connect the computer and enter the firmware update interface to upgrade the firmware.
2. After entering the firmware update, the computer recognizes the U disk and directly copies the firmware file to the U disk.
3. In the firmware update interface, long press the power button to shut down.

----------------------------------------

[ SYSTEM REQUIREMENTS ]
- Windows 10 / 11
- USB Data Cable (Data Transfer Supported)
- Stable Power Supply
