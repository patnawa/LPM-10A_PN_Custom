# TX PN 2.12 — Port FLASH fix confirmed on device

Port FLASH could pause with the switch LED continuously on because GPIO input
changes repeatedly restarted the hold timer. PN 2.12 uses the PHY's current
link status and makes the tester indicator follow the same state. The owner
confirmed the fix on a D-Link gigabit switch on 2026-09-19.

This release preserves the exact PN 2.12 image tested by the owner. It includes
all PN 2.9 features and the TX audit fixes developed in PN 2.10/2.11.

## Downloads

- `LPM-10A-TX_PN2.12-portflash-status.bin` — **TX tester only**, 393216 bytes.
- `PN2.12-README.txt` — changes, validation scope and update instructions.
- `PN2.12-SHA256SUMS.txt` — binary checksum.

SHA-256:

```text
3d2db80f8288744191fe1ddb2855a83b900166dd365e1583c6270dfb460a0076
```

## Changes since PN 2.9

- Read PHY link status for Port FLASH acquisition and hold; clear historical
  latch-low status and reject all-ones MDIO reads. The indicator uses the net
  task's published state without adding concurrent MDIO transactions.
- Correct the auto-negotiation register used by FLASH and SPEED setup.
- Restart the hold after observed link loss and measure power intervals after
  the power helper completes.
- Keep battery monitoring and low-voltage detection active during FLASH.
- Use the checked static settings writer for explicit save, default setup and
  power-off, avoiding crashes on failed heap allocation.

## Validation and limits

- **Owner confirms Port FLASH fixed** on the reported D-Link gigabit switch.
  The exact model, session duration and unplug/replug results were not recorded.
- **109 TX regression tests pass**, including 34 PN 2.12 candidate groups.
  The full default-base verifier also passes. Tests cover actual firmware
  instructions with modeled hardware/RTOS boundaries and deterministic rebuilds.
- The other new TX fixes have CPU verification; this owner report confirms
  Port FLASH specifically. Other switch models and electrical measurements
  need separate validation.

FLASH retains 10 Mb/s advertisement, 500 ms polling and 4/8/16-second retry
windows. Negotiation can produce long off gaps; this is not fixed-frequency
blinking. Settings writes remain a single-page operation and are not power-fail
atomic.

See the [Port FLASH investigation](https://github.com/patnawa/LPM-10A_PN_Custom/blob/v2.12/docs/PORT-FLASH-STATUS-2026-09-19.md)
and [full TX/RX audit](https://github.com/patnawa/LPM-10A_PN_Custom/blob/v2.12/docs/FULL-FIRMWARE-AUDIT-2026-09-19.md).
The separate [RX PN 1.5 prerelease](https://github.com/patnawa/LPM-10A_PN_Custom/releases/tag/rx-v1.5)
is optional and is not required for this Port FLASH fix.

## Build and update

From `LPM-10A/Firmware File/sdk`:

```text
python build.py --portflash-status --write
python -m unittest test_portflash_status -v
```

The SDK default and `--roadmap` profiles remain PN 2.9 comparison/reproduction
profiles; use `--portflash-status` for this release.

1. Verify the binary against the SHA-256 above.
2. With the tester off, hold **M + Power**, then connect USB-C.
3. Copy the TX file to the update drive and wait for completion.
4. Power-cycle; About should show **Software:PN 2.12**.

If the bootloader rejects the filename, use `LPM-10A-TX_V2.0.7_260610.bin`.
Keep the prior working TX image for comparison or rollback. TX and RX firmware
are not interchangeable.
