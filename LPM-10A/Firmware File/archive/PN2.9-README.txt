# TX PN 2.9 — Cortex-M4F FP crash frame fix, SHCSR fault handlers and version bump

Firmware for the **LPM-10A TX tester**. This release builds on the device-tested
PN 2.8 foundation, delivering fixes for Cortex-M4F exception frame decoding,
activating hardware configurable fault handlers in `SHCSR`, and bumping the
identity string to `PN 2.9`.

- `LPM-10A-TX_PN2.9-roadmap.bin` — 393216 bytes, all roadmap enhancements with fault diagnostics.
- `PN2.9-README.txt` — changes, update instructions and validation limits.

## Changes from PN 2.8

- **Cortex-M4F FP exception frame decoding fix:** On ARMv7-M architectures, the basic
  integer registers (`R0–R3, R12, LR, PC, xPSR`) always reside at `SP + 0` to `SP + 28`,
  even when floating-point lazy stacking is active (`EXC_RETURN` bit 4 == 0). The previous
  routine mistakenly added 72 to `SP`, reading `FPSCR` (`SP + 96`) and `S15` (`SP + 92`)
  instead of `PC` (`SP + 24`) and `LR` (`SP + 20`). The handler now reads from the base
  frame directly and unconditionally.
- **Enable configurable system faults in `SHCSR`:** Activate `MEMFAULTENA`, `BUSFAULTENA`,
  and `USGFAULTENA` (`0x00070000`) in `SHCSR` (`0xE000ED24`) at startup. Previously,
  these faults escalated to HardFault (vector 3), leaving vector entries 4, 5, and 6
  dormant. Now MemManage, BusFault, and UsageFault execute their dedicated diagnostics.
- **Identity version bump:** Updated version string to `PN 2.9` across the About
  screen and UART boot banner.
- Retains all established roadmap features: task-deferred SysTick ISR event worker,
  task-aware watchdog supervisor, atomic calibration autosave with static staging,
  and crash context retention across warm reset.

Companion probe: RX PN 1.4 ADC Timeout Fix.

## Validation and limits

- 25 SDK unit and audit tests pass (`test_roadmap`, `test_audit`).
- 71 reliability verification checks pass (`verify_reliability.py`).
- All Thumb instruction-level assembler round-trip tests pass (`test_thumb.py`).
- Floating-point and integer exception frame parsing validated under Unicorn emulation.
- Both About language branches (English / Thai) verified.

## Build, update and recovery

1. Verify: `certutil -hashfile LPM-10A-TX_PN2.9-roadmap.bin SHA256`.
2. Power off, hold **M + Power** for the update screen, then connect USB-C.
3. Copy the TX binary to the removable drive and wait for completion without
   unplugging.
4. Power on; About should display `Software:PN 2.9`.

Fallback filename: `LPM-10A-TX_V2.0.7_260610.bin`.
