สาเหตุ: พอร์ตสวิตช์มีทางไฟตรงผ่าน centre tap (Bob-Smith) ระหว่างคู่ อ่านค่าได้ใกล้กับค่าคู่สายจริง
        (เช่น 62-67 เทียบกับ 60) PN2.28 จึงเห็นว่าแต่ละเส้นต่อถึงหลายขา = "ช็อต" ทุกเส้น
แก้: เส้นผ่านเมื่อขาคู่ของมัน (1-2, 3-6, 4-5, 7-8) อยู่ในกลุ่มค่าต่ำสุด -> สายดีไม่มีทางเป็นเหลืองอีก
     หลังสวิตช์: ขาคู่ไม่ต่อแต่ต่อขาอื่น = เข้าหัวผิดคู่ (แดง)
     ไม่มีสวิตช์ (ไม่ได้เสียบ) แต่มีช็อต = เหลือง
     ข้อจำกัด: หลังสวิตช์ที่มี centre tap สายช็อตข้ามคู่แยกไม่ออกจาก centre tap (เครื่องเดิมก็ไม่เห็น)
อื่น ๆ: โหมดเครื่องรับใช้ค่ามัธยฐาน (สายหลวม 2 เส้นไม่ทำให้เส้นดีผิด), ไม่มีกล่องสีน้ำตาลหลัง
        "Not connected", บี๊บเสียครั้งเดียว, เส้นคู่ของสายขาดไม่ขึ้นเหลือง

English: PN2.29 + a Switch-mode rule that passes a row whenever its pair partner is joined, so a
good cable cannot fail on ports whose centre-tap paths read close to the pairs (owner report);
miswire = partner not joined behind a switch; shorts flagged when no switch is detected. RX rows
use the median of kept readings (review P1-B). Tests: python -m unittest test_cable_fix -v
