TX PN2.29 - Cable Test วาดสายแต่ละเส้นด้วยสีสาย LAN (T568B)
2026-09-24 - SUPERSEDED - เจ้าของ: สีถูกทุกเส้น แต่สายดีในสวิตช์ยังเหลือง (การตรวจขาคู่ของ PN2.28) -> สีสาย LAN ออกจริงใน PN2.33 (release v2.33)

ไฟล์: LPM-10A-TX_PN2.29-cable-colours.bin  (401 408 ไบต์ เท่า PN2.27A/2.28)
ย้อนกลับ: LPM-10A-TX_PN2.28-cable-check.bin หรือ LPM-10A-TX_PN2.27A-analog-alignment.bin

สีตาม T568B:
  1 ขาว-ส้ม   2 ส้ม   3 ขาว-เขียว   4 น้ำเงิน   5 ขาว-น้ำเงิน   6 เขียว   7 ขาว-น้ำตาล   8 น้ำตาล   G เงิน
  สายลายขาว (1, 3, 5, 7) = สีของเส้น + ขีดขาวทุก 12 px (สายไขว้ในโหมดเครื่องรับก็มีขีดตามเส้นทแยง)
  ตัวเลขท้ายเส้นเป็นสีเดียวกับสาย
สีผลเสียยังชนะสีสายเสมอ (ไม่มีขีดขาว): แดง = ขาด / เข้าหัวผิดคู่, เหลือง = ช็อต, เทา = G ไม่ได้ทดสอบ (Switch)
การตัดสินผลทั้งหมดเหมือน PN2.28 ทุกไบต์ (test_cable_colours ตรวจ)

เช็กลิสต์: A. About = PN2.29  B. Switch สายดี: สีตามตาราง ขีดขาวที่ 1,3,5,7, ผลเหมือน PN2.28
           C. RX unit สายตรง/ไขว้: สีและขีดขาวตามเส้น  D. สายเสีย: แดง/เหลืองเหมือน PN2.28

English: the nine wires use the T568B colours (table 0x0801E2CC, read only by the Cable Test);
pins 1, 3, 5, 7 get white dashes (5 px every 12 px, x 29..170) along straight wires and RX-unit
diagonals; result colours (red, yellow, grey) still win and get no stripes. Decisions are PN2.28's.
Build: python cable_colours.py --write (sdk).  Tests: python -m unittest test_cable_colours -v
