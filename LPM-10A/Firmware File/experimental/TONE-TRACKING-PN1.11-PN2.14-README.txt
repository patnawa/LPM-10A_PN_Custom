RX PN 1.11 changes:
- Digital retains a full 48-sample observation, updating after 16 new samples
  once the first complete window is captured. Startup still needs about 240 ms.
- Robust local code qualification plus the established clock/phase fallback.
- Code-grouped recent 16-sample strength for faster cable comparison; exact
  fallback can use an older latest-matching span.
- Analog uses normal 30 ms pulses and finer 20-160 ms quiet intervals.
- Stronger Analog results can shorten the pending gap without cutting off
  current tones or key beeps. Repeats require fresh results within 100 ms.
- An accepted Analog signal with at least 8/64 upper-rail ADC readings gives
  100 ms pulses / 160 ms quiet gaps: unsuitable for fine strength comparison.
- DFT magnitudes remain bit-exact; complete Analog analysis needs about 74%
  fewer instructions in the profiled emulator cases. Not measured CPU timing.
