Recorded as a functional device test pass. No detailed test matrix or
quantitative range/cable-selection measurements accompanied the report.

Use TX Digital with the receiver's existing digital mode. There is no new key
combination; the normal mode button still switches digital/analog operation.

Changes from PN 1.6:
- Five strength levels spread over a wider ADC contrast range.
- Remove one extreme high and low deviation from the strength score.
- Apply 10% hysteresis around grade boundaries to reduce rate switching.
- Sound fixed 30 ms pulses; stronger grades shorten the gap between pulses.
  Requested gaps, weak to strong: 160, 110, 75, 45, 20 ms.
- Stop further repeats after the first completed rejected sample window.
  If no new result arrives, repeats expire 300 ms after the last accepted one.
- Let active tones finish, including 100 ms key confirmation. Retain the
  separate 800 ms recent-signal hold for idle auto-off protection.

The digital window remains approximately 240 ms. Faster release deliberately
provides less smoothing of occasional missed windows; weak or drifting signals
may sound less continuous than PN 1.6. Thresholds are provisional and do not
represent cable distance or calibrated sensitivity. Adjacent cables carrying
the same coupled code can still be detected.

Includes every PN 1.6 fix. Signal eligibility, ADC transactions, sampling,
analog/mains analysis, buttons, battery handling, timer configuration, image
size, and binding/version handling retain their prior behavior. No additional
persistent RAM or countdown timer is allocated. Earlier binaries are retained.
