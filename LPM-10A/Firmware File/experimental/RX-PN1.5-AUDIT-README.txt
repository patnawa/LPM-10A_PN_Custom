Includes all PN 1.4 roadmap features and two corrections:
- Clear the mains sample buffer before allowing TIM5 to fill it again.
- Keep DFT squared values in double precision so strong valid ADC signals
  no longer overflow to zero in analog and mains detection.

No image growth or extra persistent RAM. Digital detector, sampling rates,
UID/device-binding logic and vendor-facing version 3.0.0 are preserved.
Identify this candidate by its filename and SHA-256, not the version screen.
Build input remains APP_LPM-10RX_V3.0.0_260416.bin.

Use the RX update procedure documented in ../RX-PN1.4-README.txt: with the
probe off, hold Power until its LED illuminates, connect USB-C and copy the
RX file to the update drive; wait for completion, then power-cycle. Retain
the prior working RX image. Compatibility with other revisions is unverified.

Check digital, analog and mains modes with strong/weak signals, mode changes,
lamp, keys, power-off and a sustained session. Emulated DFT accuracy does not
establish real detection distance or mains calibration.
