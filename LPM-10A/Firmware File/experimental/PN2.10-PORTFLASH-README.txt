Includes all PN 2.9 roadmap features and three Port FLASH fixes:
1. Enable/restart auto-negotiation through PHY register 0, not register 4.
2. Restart the full link hold after an observed link loss and recovery.
3. Time the dark/relink intervals after the PHY power call completes.

For the owner's report that the port blinks a few times and stops. The software
defects are reproduced; the exact cause on the owner's switch is unconfirmed.
The 10 Mb/s advertisement and 16-second maximum negotiation window remain.

update mode, connect USB-C, and copy this file to the update drive. After the
update completes, power off/on and confirm About reports Software:PN 2.10.

described in the repository's TX installation instructions.
