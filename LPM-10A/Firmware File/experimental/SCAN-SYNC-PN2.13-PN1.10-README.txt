TX SCAN mode key cycles:
1. Digital 454 kHz - existing B6 digital waveform; earlier RX compatible.
2. Analog 825 Hz - existing analog tone; use RX analog mode.
3. Sync32 454 kHz - new longer code; requires RX PN 1.10 digital mode.
4. Pulse test - diagnostic carrier, nominal 99.99 ms ON / 399.96 ms OFF.

Digital/Sync32 labels show carrier frequency. Analog shows tone modulation
frequency; it also uses the same approximately 454 kHz carrier. Values are
rounded nominal settings, not measurements. Technical labels are shared by
English and Thai UI modes. Carrier hardware and output power are unchanged.

RX PN 1.10 automatically recognizes both digital codes in its existing
digital mode. It includes PN 1.9 robust median-based strength feedback.
TX starts in original Digital mode. Back pauses; a second Back exits.
Pulse test is for envelope/settling measurements, not cable identification.

Sync32 improves some modeled noisy conditions but is more sensitive to
clock mismatch and has narrow clean sampling blind spots. Keep Digital
available; select it if Sync32 is intermittent. No physical range or bundle
selectivity improvement, or superiority to Fluke, has been measured.
