HOW TO UPDATE (full guide, Thai + English: docs/RX-UPDATE-GUIDE.md;
               investigation: docs/RX-UPDATE-PROCEDURE-2026-09-21.md)
  1. Probe off. Hold SCAN, plug USB. A drive named BOOTLOADER appears.
  2. Copy the *-update.bin file onto it with Explorer (ordinary copy).
  3. Within about a second the drive disappears: the probe has programmed the
     file and restarted into it. Unplug USB; press the power key if it waits.
  Only the -update.bin container is accepted. A raw image is silently ignored
  (the status file stays UNKOWN.TXT). Do not use a slow or streaming copy tool.
  Roll back: build the factory V3.0.0 container (rx-sdk: wrap the vendor file)
  and copy it the same way; verified on this unit.

WHAT YOU HEAR
  - Digital: 2.5 kHz pulses (30 ms). Analog: 1.25 kHz pulses, one octave lower.
    Mains: 5 kHz (its three-tier beep length is unchanged).
  - Key beeps chirp: entering Digital = low->high, Analog = high->low; the
    boot beep is high->low; the lamp key chirps toward the current mode.
  - The pulse rate reports how close the probe is to the cable, not the knob
    position: the quiet interval runs 110 ms (weakest accepted) to 20 ms
    (strongest). Turning the sensitivity knob no longer speeds the rhythm; it
    only sets how weak a signal is still accepted, as on the stock firmware.
  - The knob now has monotonic gain steps low / 230 / 780 / 780 / high (the
    stock firmware dropped the 43-56 % range to the lowest gain).
  - A momentary missed window keeps the rhythm going (160 ms Digital, 60 ms
    Analog); a signal that is really gone still stops within ~1/4 s.
  - Each new reading moves the rhythm half way toward its target, so noise
    does not make it jump; it settles in 2-3 updates.
  - Touching the cable gives the fastest rhythm at every knob position, and
    then (PN 1.22) the gain steps down by itself: peak-to-peak >= 1900 counts
    drops one gain step (high -> 780 -> 230 -> 90), < 450 steps back up to the
    knob, 2 s hold, moving the knob resets. The rhythm is normalised by the
    gain actually driven, so two strong cables stay distinguishable without
    touching the knob.
  - Digital evaluates every 40 ms (PN 1.21; was 80), so its rhythm follows
    the probe as you move it.

  PN 1.14 rx-mode-tone     per-mode speaker cadence + chirp (TIM5 dispatch -> helper)
  PN 1.15 rx-gain-norm     score x measured knob gain step; curve floor 160 -> 110 ms
  PN 1.16 rx-release-hold  rejected window keeps rhythm, RECENT clamped 660/560
  PN 1.17 rx-smooth-gain   knob level 3 -> level 2 gain pattern; half-step smoothing
  PN 1.18 rx-rail-strong   'uncertain' (clipped) reading -> fastest rhythm
  PN 1.19 rx-strong-cap    curve's fastest point 88 000 -> 40 000 (front-end saturation)
  PN 1.20 version tag      version string "PN1.xx" -> status file names the build
  PN 1.21 rx-fast-update   Digital overlap 40/8: evaluate every 40 ms
  PN 1.22 rx-auto-range    automatic gain step-down on saturation (2 s hold)
  PN 1.23 rx-mains-tone    mains mode at 5 kHz
  Detection, sampling, release logic and device binding are PN 1.12's. The image
